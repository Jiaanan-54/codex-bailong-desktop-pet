# v1.10.1

- **macOS 原生深度适配**
  - 支持自动探测 macOS 环境下安装的官方 ChatGPT.app 及其内置的 codex-cli 工具路径。
  - 针对 macOS 进程树与窗口管理器（AppleScript / lsappinfo / pgrep）深度优化，支持桌面 ChatGPT 前台唤起与平滑热重启。
  - 新增 `run_mac.py` 原生启动器与全套跨平台兼容补丁。

- **多账户面板交互与视觉优化**
  - **工具栏整合**：顶部单行紧凑排列「新增账户 / 导入账户 / 全部刷新 / 全部续期」，统一原生悬停手势指针。
  - **卡片栅格重构**：账户卡片采用双行对称排布——首行展示「名称 / 账户」，次行展示「等级 / 按钮列」，消除多余留白与对齐偏差。
  - **规格统一**：「当前账户」与「切换账户」采用一致的固定几何尺寸与圆角。
  - **紧凑进度条**：详情面板中的「凭证有效期」、「本周周额度」、「五小时额度」重构为单行紧凑进度条，凭证有效期满值基准严格设定为 10 天。
  - **分界线与自动渐隐**：切换成功提示弹窗最多保留 10 秒后自动淡出；多卡片间加入半透明质感分割线，提升视觉层级。

已有用户可在「设置 → 维护 → 软件更新」升级，或直接下载本版本对应的 Windows / macOS 便携包解压运行。
